# Xnotes - The BICT Resource Hub

## Overview
Xnotes is a centralized, interactive web application developed as a student resource hub designed to facilitate the efficient sharing, organization, and retrieval of academic resources. 
The application aims to cultivate a collaborative learning environment where undergraduates can seamlessly upload study materials, access peer-shared notes, and enhance their academic productivity through a well-structured digital repository.

## Target Audience
The platform is exclusively designed for undergraduate students, specifically targeting the Bachelor of Information and Communication Technology (BICT) undergraduates at Rajarata University of Sri Lanka.

## Core Features
* **Secure User Authentication & Profile Management:** Features a robust registration and login system utilizing encrypted passwords, allowing users to safely manage their sessions and uploaded resources.
* **Dynamic Resource Management System:** Authorized users can upload, categorize, and browse academic materials (such as PDFs and images) based on specific subject modules.
* **Advanced Search and Filtering:** Integrates real-time search functionality with interactive UI elements, enabling users to instantly locate specific study materials using keywords or category filters

## Technology Stack
* **Frontend Structure & Design:** HTML5, CSS3, Bootstrap 5
* **Client-side Scripting:** Vanilla JavaScript
* **Backend Processing:** PHP 8
* **Database Management:** MySQL (via XAMPP)
* **Version Control & Collaboration:** Git & GitHub
